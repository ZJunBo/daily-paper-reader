## 摘要
在大语言模型（LLM）的高风险决策应用中，从业者不仅需要准确的 LLM，还需要对其预测进行不确定性估计。现有的 LLM 不确定性估计方法需要访问模型输出的对数概率，或需要微调权限。然而，许多工业级 LLM 产品使用闭源 API 模型，而许多此类 API 模型（如 GPT）不返回对数概率，并且可能不允许微调。我们提出 Pinocchio，一种外部校准器，用于估计黑盒 API 模型响应的正确性。它在七个 LLM 的响应上联合训练，在预测这些相同模型留出响应的正确性时达到 0.862 AUROC，并展现出对来自八个机构的十三个未见模型的零样本迁移能力。我们的模型仅需一次前向传播即可生成不确定性估计，且无需访问目标模型的 logits、权重或内部状态。一个轻量级的纯文本 0.8B 检查点即可匹配我们最大模型的 AUROC。我们发布了代码，只需额外两行代码即可将不确定性估计添加到现有代码库中。

## Abstract
In high-stakes decision-making applications of large language models (LLMs), practitioners require not only accurate LLMs but also uncertainty estimates for their predictions. Existing approaches to uncertainty estimation for LLMs require access to log-probabilities output by the model or require fine-tuning access. However, many industrial LLM products use closed-source API models, and many such API models like GPT do not return log-probabilities and may not allow fine-tuning. We introduce Pinocchio, an external calibrator that estimates the correctness of responses from black-box API models. Trained jointly on responses from seven LLMs, it achieves 0.862 AUROC predicting the correctness of held-out responses from those same models, and shows zero-shot transfer to thirteen unseen models across eight organizations. Our model needs only a single forward pass to generate an uncertainty estimate and requires no access to the target model's logits, weights, or internal states. A lightweight text only 0.8B checkpoint matches our largest model's AUROC. We release code for adding uncertainty estimation to existing repos in only two additional lines of code.

- **现有方法的根本张力**：基于 logit/表征的方法需要白盒访问权限；黑盒替代方案各有代价——verbalized confidence 校准差，self-evaluation 继承模型盲区，semantic entropy 需要 5–10 倍推理预算。
- **整体含义**：论文提出 **Pinocchio**，一个在 (问题, 响应, 可选模型标识, 可选图像) 上训练的外部校准器，**仅需一次前向传播**即可输出响应正确概率 `P(correct)`，无需访问目标模型的 logits、权重或内部状态，为黑盒 API 模型提供实用、低成本的不确定性估计。

## 2. 方法论

- **核心思想**：不直接从目标模型内部提取不确定性，而是训练一个小型外部校准器，从"问题 + 响应文本（+ 图像 + 元数据）"中学习预测该响应是否正确。采用监督学习范式，输入为目标模型的输出对，输出为二分类正确性概率。
- **模型架构**：以 **Qwen3-VL-8B-Instruct** 为基座，使用 **LoRA（rank 32, α=64）** 微调所有线性层；文本任务使用 28×28 灰色占位图填充图像槽，统一文本与视觉语言输入格式。
- **训练目标**：模型在最后位置预测单个 token——`i`（不正确）或 `ii`（正确），通过 softmax 提取正确概率：

  `P(correct) = exp(z_ii) / (exp(z_i) + exp(z_ii))`

  仅在最后 token 上计算交叉熵损失。
- **输入格式**：包含 Benchmark 名称、来源模型标识、问题、回答，以及结尾提问"Is the answer correct? (i) No (ii) Yes"。加入元数据使 AUROC 从 0.813 提升至 0.863。
- **关键设计**：
  - **模型标识标签（model-identity tag）**：训练时允许校准器利用模型特定模式，推理未见模型时可省略。
  - **多模型联合训练**：在 7 个能力跨度较大的 LLM 响应上联合训练（Claude Fable 5、Claude Opus 5、GPT-5.6、Kimi 3、GPT-5-mini、GPT-5.2、Qwen3.5-397B），共 20 个 benchmark、32,419 条训练响应（17,778 视觉语言 + 14,641 文本）。
  - **拒答与空响应**：保留并标注为 incorrect。
  - **问题级划分**：同一问题的所有模型响应归入同一 split，避免近重复样本泄漏。

## 6. 主要结论与发现

- **同批留出表现**：Pinocchio 在留出响应上达到 **0.862–0.863 AUROC**，远高于最强单次黑盒基线（combined，0.649），且校准显著优于 raw verbalized confidence（ECE 0.107 vs 0.299）。

- **小模型高效**：**0.8B 纯文本 checkpoint 保留最大模型 99% 的 AUROC**，校准器规模影响很小，训练数据量影响更大。

- **视觉语言数据的迁移增益**：VLM 训练数据在文本数据稀缺时显著提升文本校准（+0.041–0.059 AUROC），随文本样本增多收益递减。
- **采样基线在困难推理上失效**：忠实同目标采样方法（semantic entropy、self-consistency、SPUQ、共形预测）在困难套件上接近随机，增加采样数无改善；在简单短答 benchmark 上则表现正常。

- **跨模型泛化强**：单一 checkpoint

- **跨模型泛化强**：单一 checkpoint 即可覆盖 7 个训练模型与 13 个未见模型（跨 8 个机构），且对训练后新发布的模型仍保持约 0.81 AUROC，说明校准器学到的是"响应—问题"之间的可迁移正确性信号，而非某一模型的指纹。
- **成本优势显著**：一次前向约 0.1 秒，无需多次采样或访问目标模型 logits，相比 semantic entropy / self-consistency 的 5–10 倍推理预算，在生产环境中具有可观的吞吐与延迟优势。
- **可扩展的规模规律**：0.8B 即可保留 8B 模型 99% 的 AUROC，训练数据呈对数线性收益，为不同预算的团队提供了清晰的成本—性能权衡曲线。
- **多模态与跨域复用**：同一架构统一处理文本与视觉语言输入，VLM 数据在文本数据稀缺时反哺文本校准，并成功迁移到 T2I 评估、DPO 配对选择、模型选择、数据过滤等下游任务。
- **实验严谨**：问题级划分、DeLong 检验、BCa bootstrap、置换检验、难度分层与难度控制分歧测试共同支撑了"校准器读响应而非判难度"的核心论断，消融维度覆盖模型规模、数据规模、输入字段、抽取策略、领域与响应长度。

## 8. 局限与不足

- **依赖外部标注的正确性标签**：训练需要 (问题, 响应, 正确/错误) 三元组，而 20 个 benchmark 中有 5 个使用 GPT-5-mini 自动评分，论文仅做了 0.14% 的标签审计，未提供人类一致性验证，标签噪声可能同时影响训练与评估上限。
- **AUROC 之外的校准质量**：主指标以 AUROC 为主，ECE（15 bins）与 Brier 虽有报告，但在高置信度区间（如 >0.9）的可靠性、以及面向风险决策的分位数校准（如 conformal / risk-coverage）讨论相对有限；生产用例的覆盖率结论仍依赖特定阈值设定。
- **对目标模型分布漂移的稳健性**：零样本迁移验证的是"训练后新模型"，但未系统检验目标模型发生行为漂移（如系统提示变化、工具调用、长链推理、RAG 上下文注入）时的性能衰减，也未覆盖 agentic 多轮轨迹中的逐步正确性。
- **视觉语言任务覆盖不均**：虽然使用了 11 个 VLM benchmark，但图像—问题—响应之间的细粒度错误（如局部区域幻觉、图表读数错误）是否能被单次前向的 8B 校准器可靠捕捉，仍缺乏按错误类型分解的证据。
- **拒答与空响应的处理较为粗暴**：统一标注为 incorrect 会在"合理拒答"场景（如安全合规、信息不足）下产生系统性偏置，可能低估模型在安全敏感场景中的可用性。
- **推理成本只披露单查询延迟**：未给出总 GPU 小时、能耗、或在不同 batch/并发下的吞吐数据，也未与基线在同等硬件条件下的端到端成本做严格对比，成本优势的量化略显单点。
- **基线的可复现性**：部分基线（如 SPUQ、Su et al. 共形预测、Lin et al. 图论度量）的实现细节与超参在正文中未充分展开，复现与公平比较存在一定门槛。
- **训练数据来源与许可**：7 个目标模型覆盖闭源与开源，但训练响应的生成成本、许可与是否可发布 checkpoint/数据未详细说明，影响社区复用。

## 9. 对实践与后续研究的启示

- **对工程实践**：Pinocchio 提供了一条"黑盒可用、单次前向、即插即用"的不确定性路径，适合作为 API 模型之上的轻量校准层，用于置信度门控、人工升级分诊、agentic 动作前检查与数据过滤。
- **对方法研究**：论文的核心洞察——"正确性可以从响应文本本身被外部读出"——与白盒 log-prob / 采样一致性形成互补；在困难推理任务上后两者失效的发现，提示不确定性研究应从"模型内部信号"转向"响应级证据与可验证性"。
- **对评估范式**：零样本跨模型迁移 + 训练后新模型 + LOMO/LODO 的组合评估协议，为不确定性估计器提供了比单一留出集更可信的泛化证据，值得作为该方向的标准做法。
- **对多模态**：VLM 数据对文本校准的正向迁移提示，多模态 benchmark 的高错误率可作为"困难样本矿"，是低成本提升校准器鲁棒性的有效数据策略。
- **待探索方向**：面向多轮对话与 agent 轨迹的逐步不确定性、面向拒答/安全场景的成本敏感校准、以及在目标模型持续更新下的在线适应与漂移检测，都是 Pinocchio 框架自然延伸的空间。
