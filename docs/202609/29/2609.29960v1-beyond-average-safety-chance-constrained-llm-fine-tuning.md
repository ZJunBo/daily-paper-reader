## 摘要
在新目标上微调大语言模型可以提升有用性、指令遵循能力或特定领域性能，但也可能在安全关键提示上引发性能退化。现有的安全保持微调方法通常控制平均安全损失或使用加权辅助惩罚，这可能掩盖罕见但严重的失败。我们提出一种用于安全保持微调的机会约束形式化方法，限制相对于参考模型退化超过给定阈值的安全样本比例。由于由此得到的经验机会约束包含不连续指示函数，我们引入对违规率的可微上界化，得到一个可处理的保守约束。然后，我们开发一种约束感知梯度下降方法，将上界化后的约束视为参数空间中的安全集，并以最小方式修改微调方向以保持可行性。所得更新具有闭式形式，并产生尾部感知的安全校正，强调接近或超过退化阈值的样本。我们在三个不同任务和三个模型上对有害微调进行了大量实验，表明我们的方法始终优于文献中已有的基线。这些结果表明，LLM微调中的安全保持最好被视为可靠性约束优化问题，而非平均风险正则化。

## Abstract
Fine-tuning large language models on new objectives can improve helpfulness, instruction following, or domain-specific performance, but it can also induce regressions on safety-critical prompts. Existing safety-preserving fine-tuning methods typically control average safety loss or use weighted auxiliary penalties, which can obscure rare but severe failures. We propose a chance-constrained formulation for safety-preserving fine-tuning that limits the fraction of safety examples whose degradation relative to a reference model exceeds a prescribed threshold. Because the resulting empirical chance constraint contains a discontinuous indicator, we introduce a differentiable majorization of the violation rate, yielding a tractable conservative constraint. We then develop a constraint-aware gradient descent method that treats the majorized constraint as a safe set in parameter space and minimally modifies the fine-tuning direction to preserve feasibility. The resulting update admits a closed form and produces a tail-aware safety correction that emphasizes examples near or above the degradation threshold. We conduct an extensive set of experiments on harmful fine-tuning across three different tasks and three models and show that our approach consistently outperforms the baselines that exist in the literature. These results suggest that safety preservation in LLM fine-tuning is better viewed as a reliability-constrained optimization problem than as average-risk regularization.

## 1. 核心问题与整体含义

- **研究动机**：大语言模型在下游任务（有用性、指令遵循、领域专精）上进行微调时，可能意外地损害其在安全关键提示上的行为，即"有害微调"（harmful fine-tuning, HFT）现象。即便微调数据本身是良性的，这一退化仍会发生。
- **现有方法的核心缺陷**：主流防御方法通过加权平均或正则化将微调损失与安全损失耦合，只控制**平均安全损失**。作者用命题 2.1 严格证明：即使平均退化很小（E[Z] ≤ μ），仍可能存在一小部分样本发生严重退化（P(Z > τ) ≥ α，只要 ατ < μ）。即**均值控制不能保证可靠性**。
- **整体含义**：作者主张将安全保持重新表述为**可靠性约束优化问题**，而非平均风险正则化。核心是限制"退化超过阈值的安全样本比例"，而非限制平均退化。

## 2. 方法论

- **核心思想**：将安全保持形式化为机会约束（chance constraint）——要求退化超过阈值 τ 的样本比例不超过容忍水平 α，即 P(∆ℓsafe(θ) ≤ τ) ≥ 1−α；在有限数据集上即经验违规率 ≤ α。

- **关键技术细节**：
  - **安全退化定义**：∆ℓsafe_i(θ) = ℓsafe_i(θ) − ℓsafe_i(θ0)，即相对于参考模型 θ0 的交叉熵退化，剔除了样本本身难度。
  - **可微上界化（majorization）**：用非负可微函数 ϕβ 替代不连续指示函数，满足 1{z>0} ≤ ϕβ(z)，得到保守充分条件 gβ(θ) = (1/n)Σϕβ(∆ℓsafe_i − τ) − α ≤ 0。
  - **与熵风险的联系**：取指数型 majorizer ϕβ(z)=exp(βz)，则约束等价于经验熵风险（entropic risk）约束 ρβ,n(∆ℓsafe − τ) ≤ (1/β)log α。
  - **约束感知梯度下降**：将 Cβ = {θ : gβ(θ) ≤ 0} 视为参数空间中的安全集，要求前向不变性条件 d/dt gβ(θ) ≤ −κgβ(θ)。每步求解"距离名义微调梯度最近的、满足该仿射约束的方向"这一二次规划问题。
  - **闭式解**：d*(θ) = −∇LSFT(θ) − λ*(θ)∇gβ(θ)，其中 λ*(θ) = ((−∇gβ⊤∇LSFT + κgβ)/‖∇gβ‖²)+。可行时退化为普通 SFT 梯度，不可行时施加最小修正。
  - **尾部感知权重**：安全校正由 ϕ′β(∆ℓsafe_i − τ) 加权，强调接近或超过阈值的样本。
  - **随机实现**：用 minibatch 估计，并引入缓冲约束 ĝβ^buf = ĝβ + ρ 缓解采样噪声导致的违约。算法流程见 Algorithm 1。
  - 实验中使用单侧 ramp majorizer：ϕβ(z) = max(1+βz, 0)。

- **数据集/场景**：

## 6. 主要结论与发现

- **总体**：本文方法在几乎所有配置中达到或接近最低 HS 和 HS_qK，且安全水平与对齐模型基本相当，同时保持可接受的任务准确率。
- **分类任务（SST-2/AG News）**：抑制有害性与任务学习不冲突，本文方法在最低/近最低有害性下准确率仅略低于最强效用基线；而 Vaccine、Booster 在高投毒比下 HS 甚至超过无防御 SFT。
- **GSM8K**：约束真正"活跃"，安全-效用权衡明显。本文方法是唯一在保持有害性于对齐水平的同时提升任务准确率的方法；部分基线 HS 更低但准确率仅约本文一半（属模型退化而非约束满足）。
- **投毒比扫描**：本文方法的有害性指标对投毒比近似不变（p 从 5% 升至 50% 仍近乎恒定），而无防御 SFT 的有害性稳步上升。
- **Antibody 组合**：约束以相对退化定义，与任意对齐过程兼容；在 GSM8K 上组合配置达到最低 post-attack HS。
- **Primal-Dual 对比**：效用相近，但本文方法在 AG News/GSM8K 上有害性更低，体现 anytime-feasibility 优势。

## 7. 优点

- **问题视角新颖**：首次将安全保持明确表述为机会约束/可靠性约束，并用命题证明均值控制的根本局限，理论动机清晰。
- **方法优雅**：可微 majorization 提供可处理保守约束，指数 majorizer 与熵风险自然联系；约束感知梯度下降有闭式解，无需调参惩罚权重或反应式对偶变量，且具有 anytime 可行性保证。
- **尾部感知**：校正权重自动聚焦接近/超过阈值的样本，直接针对罕见严重失败。
- **与 SFT 兼容**：可行时退化为标准微调，计算开销仅约 2×（优于 SafeGrad 2.38×、AsFT 3.73×）。
- **实验扎实**：多模型多任务多种子、含尾部统计、超参稳健性、投毒比扫描、组合与消融实验，结论有支撑。

## 8. 不足与局限

- **需额外安全数据集**：约束需在独立安全集上实例化（虽为 HFT 框架惯例）。
- **计算开销**：每步额外一次前向/反向，约使 wall-clock 翻倍；虽提供 primal-dual 折中方案，但会牺牲部分逐步可行性保证。
- **安全度量代理简单**：约束仅用安全样本上的交叉熵，可能未完全捕捉对齐阶段获得的额外安全性（Antibody 组合实验显示 filter 保持参考模型不够紧）。
- **超参未按参考模型重调**：τ 为绝对 nats 预算，对更低损失的参考模型可能需更紧的 τ，作者未逐参考模型重调。
- **实验覆盖偏差**：投毒比扫描仅在 Qwen-3.5-4B 上完整进行，其他模型未做同等扫描；GSM8K 上部分结果方差较大。
- **固定数据集约束**：未在策略自身生成上定义约束；作者将基于奖励模型的 on-policy 安全约束列为未来工作。
- **基线对齐预算不一致**：部分对齐阶段防御用 20 epoch 而标准对齐用 3 epoch，可能影响对比公平性。
