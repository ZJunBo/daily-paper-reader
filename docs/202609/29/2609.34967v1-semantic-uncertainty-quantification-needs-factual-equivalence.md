## 摘要
大语言模型的语义不确定性量化依赖于一个常见模板：采样若干答案，度量它们的一致程度，并将分歧视为不确定性。我们首先将该模板形式化为两个独立的角色：一个比较两个答案的算子，以及一个将所有成对比较组合为标量的聚合器。现有方法几乎完全在聚合方式上有所不同，而算子则直接采用现成组件，通常是 NLI 模型或通用句子编码器。我们表明，这种对现成算子的依赖是语义 UQ 的主要瓶颈：它们无法准确度量对同一问题的多个答案之间的事实等价性。我们用一个刻意简单的方案解决该问题：单个编码器以对比方式训练，以分离出目标事实，所用合成数据由 LLM 生成，且数据集与所有评估设置均不相交。将所得算子集成到现有方法中，在涵盖语言模型和视觉语言模型的 18 个模型-数据集组合的 126 个评估设置中的 120 个（95%）上提升了性能。最佳变体达到 0.76 的平均 AUROC，而最强基线为 0.68，同时将基于蕴含算子的二次交叉编码器比较替换为每个答案一次编码器前向。改进的一致性支持这一观点：限制因素是算子，而非聚合器。同一算子还能改进单次生成 token 级估计器：它为每个 token 赋予的范数度量了该 token 对答案的重要程度，并据此重新加权 token 对数似然，从而使估计更精确。

## Abstract
Semantic uncertainty quantification for large language models rests on a common template: sample several answers, measure how much they agree, and treat disagreement as uncertainty. We first formalize this template as two separate roles: an operator that compares two answers, and an aggregator that combines all pairwise comparisons into a scalar. Existing methods differ almost entirely in how they aggregate, while taking the operator off the shelf, typically an NLI model or a generic sentence encoder. We show that this reliance on off-the-shelf operators is the primary bottleneck of semantic UQ: they do not accurately measure factual equivalence of multiple answers to the same question. We resolve this with a deliberately simple recipe: a single encoder trained contrastively to isolate the targeted fact, utilizing synthetic data generated by an LLM and dataset both disjoint from all evaluation settings. Integrating the resulting operator into existing methods improves performance on 120 of 126 evaluation settings (95%) spanning 18 model dataset combinations across language and vision-language models. The best variant reaches 0.76 mean AUROC against 0.68 for the strongest baseline, while replacing the quadratic cross-encoder comparisons of entailment-based operators with one encoder pass per answer. The uniformity of the improvement supports the view that the operator, not the aggregator, is the limiting factor. The same operator also improves single generation token-level estimators: the norm it assigns to each token measures how much that token bears on the answer, and reweighting token log-likelihoods accordingly sharpens the estimate.

- **语义 UQ 的通用模板**：采样 N 个答案 → 两两比较 → 将比较结构聚合为标量，形式化为 `U = F(S)`，其中算子 `s` 生成 N×N 比较矩阵 S，聚合器 `F` 将其汇总为标量。
- **核心论点**：现有工作（SE、CAE、KLE、COS）几乎全部聚焦于设计更精巧的**聚合器 F**，而把**算子 s** 当作次要设计选择、直接从现成组件（NLI 交叉编码器、通用句编码器、内部隐状态）继承。本文主张：**算子才是语义 UQ 的真正瓶颈**，因为现成算子无法准确度量同一问题下多个答案之间的**事实等价性**。

## 2. 方法论

### 核心思想
放弃现成度量空间与外部 NLP 数据集，**直接从目标语言模型自身的"预测变异性"中提取原生语义几何**，训练一个专用的、问题条件化的事实等价 bi-encoder 算子。

### 三大设计准则（Desiderata）
- **(D1) 对生成语法的不变性**：对不对称详略、单词片段、共享因果后缀等 pθ 分布伪影保持鲁棒。
- **(D2) 问题条件化的事实等价**：显式锚定问题 x_text，不度量泛化主题相似度或方向性逻辑，而判断两个生成是否指称同一事实答案。
- **(D3) 计算可扩展性**：独立编码每个序列，以 O(N) 次前向构建矩阵，避免 O(N²) 的交叉编码器瓶颈。

### 关键技术细节

**（1）架构：问题条件化双编码器**
- 初始化预训练 transformer 编码器 E_ψ（如 DeBERTa、sentence-t5-large）。
- 输入为 `x_text [SEP] y^(i)`，取最后一层隐状态做 mean pooling 并 L2 归一化，得到稠密向量 φ_i。
- 算子定义为内积：`s_ψ(y^(i), y^(j) | x_text) = ⟨φ_i, φ_j⟩`。
- 由于每个生成只编码一次，构建 S 仅需 N 次前向 + 快速点积，成本从 O(N²) 降至 O(N)。

**（2）训练数据：利用预测变异性做弱监督**
- 核心假设：对同一问题的所有**正确答案**（无论长度或措辞）属于同一语义等价类；正确性天然诱导精确的成对语义关系：
  - `C_i = C_j = 1 ⟹ g_x(y^(i)) = g_x(y^(j))`（正对）
  - `C_i ≠ C_j ⟹ g_x(y^(i)) ≠ g_x(y^(j))`（负对）
- 构造流程：在 NQ-OPEN val（3,160 问题）上用 Llama-3.1-8B-Instruct 采样 N=10 个回答（temperature 1.0, top-p 0.9, top-k 50），用 **Qwen2.5-32B-Instruct** 作为 LLM-judge 标注每个回答的正确性；仅保留 |P|≥2 且 |N|≥1 的问题（1,720 个），每轮均匀采样三元组 `y_a ∼ P, y⁺ ∼ P\{y_a}, y⁻ ∼ N`。
- 完全不需要人工语义标注或 UQ 置信度标签。

**（3）目标函数：对比事实等价**
- 最小化三元组损失：
  `L_triplet = (1/B) Σ_k [⟨φ_a^k, φ⁻_k⟩ − ⟨φ_a^k, φ⁺_k⟩ + m]_+`，margin m = 0.2。
- 负样本为**硬负样本**：与锚点同问题、同主题、常共享句法结构，仅事实断言不同，迫使编码器把几何权重完全放在承载答案的事实指称上。

**（4）推理与接入现有聚合器**
- 冻结编码器，生成对称正半定 Gram 矩阵 S^E，作为通用即插即用算子替换：
  - **SE / CAE**：对 S^E 阈值化（τ = 0.5）得到聚类划分，喂给原聚合器 → SE_Enc、CAE_Enc。
  - **KLE**：直接传入连续矩阵，原样应用图拉普拉斯、热核/Matern 核扩散与 von Neumann 熵 → KLE-Heat_Enc、KLE-Matern_Enc。
  - **COS**：用问题条件化嵌入 φ_i 替换原表征，应用原谱熵计算 → COS_Enc。
- 论文只改矩阵，不改聚合器，从而把性能提升完全归因于算子瓶颈的解决。

**（5）token 级重加权的副产品**
- 归一化向量的方向承载语义，各 token 的范数 `‖h_t‖_2` 决定其对方向的贡献，可视作语义重要性。
- 将范数归一化为权重 w_t（丢弃问题与特殊 token），对 token 熵做加权：`U_TE-Enc = Σ_t w_t H_t`。
- 由于编码器与生成模型 tokenizer 不同，需做序列对齐映射。

- 训练用的 NQ-OPEN 不出现在任何评测中，训练生成模型（Llama-3.1-8B）也非任何评测模型。

### 生成与标签
- 每问题采样 N=20 个答案（temperature 1.0, top-p 0.9, top-k 50），并记录 greedy 生成及 token 级分布。
- 正确性标签：由 **Llama-3.1-70B-Instruct** 对 greedy 答案做 LLM-as-judge（主结果）；另有 majority-vote 版本作对照。训练与评测使用**不同的 judge**（Qwen2.5-32B vs Llama-3.1-70B）。

- **AUROC**：不确定性分数将错误生成排在正确生成之上的能力（0.5 为随机）。

### 对比方法（7 个估计器，各配 base 与 Enc 版本，共 126 个评测设置）
