## 摘要
大语言模型的语义不确定性量化依赖一个通用模板：采样若干答案，度量它们之间的一致程度，并将分歧视为不确定性。我们首先将该模板形式化为两个独立的角色：一个比较两个答案的算子，以及一个将所有成对比较聚合为标量的聚合器。现有方法几乎只在聚合方式上有所不同，而算子则直接取用现成模型，通常是 NLI 模型或通用句子编码器。我们表明，这种对现成算子的依赖是语义不确定性量化的主要瓶颈：它们无法准确度量同一问题的多个答案之间的事实等价性。我们用一个刻意简单的方案解决这一问题：以对比方式训练单个编码器来隔离目标事实，所用由 LLM 生成的合成数据与数据集均与所有评测设置不相交。将由此得到的算子集成到现有方法中，在覆盖 18 种模型-数据集组合（横跨语言模型与视觉-语言模型）的 126 个评测设置中的 120 个（95%）上提升了性能。最佳变体达到 0.76 的平均 AUROC，而最强基线为 0.68；同时，它用每个答案一次编码器前向替代了基于蕴含的算子所需的二次方交叉编码器比较。改进的一致性支持了这样一种观点：限制因素在于算子，而非聚合器。同一算子还能改进单次生成的 token 级估计器：它为每个 token 赋予的范数度量了该 token 与答案的相关程度，据此对 token 对数似然进行重加权可使估计更加精确。

## Abstract
Semantic uncertainty quantification for large language models rests on a common template: sample several answers, measure how much they agree, and treat disagreement as uncertainty. We first formalize this template as two separate roles: an operator that compares two answers, and an aggregator that combines all pairwise comparisons into a scalar. Existing methods differ almost entirely in how they aggregate, while taking the operator off the shelf, typically an NLI model or a generic sentence encoder. We show that this reliance on off-the-shelf operators is the primary bottleneck of semantic UQ: they do not accurately measure factual equivalence of multiple answers to the same question. We resolve this with a deliberately simple recipe: a single encoder trained contrastively to isolate the targeted fact, utilizing synthetic data generated by an LLM and dataset both disjoint from all evaluation settings. Integrating the resulting operator into existing methods improves performance on 120 of 126 evaluation settings (95%) spanning 18 model dataset combinations across language and vision-language models. The best variant reaches 0.76 mean AUROC against 0.68 for the strongest baseline, while replacing the quadratic cross-encoder comparisons of entailment-based operators with one encoder pass per answer. The uniformity of the improvement supports the view that the operator, not the aggregator, is the limiting factor. The same operator also improves single generation token-level estimators: the norm it assigns to each token measures how much that token bears on the answer, and reweighting token log-likelihoods accordingly sharpens the estimate.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大语言模型（LLM）与视觉语言模型（LVLMs）易产生"幻觉"，即在流畅自信的输出中给出缺乏依据的答案，因此需要不确定性量化（UQ）来判定输出何时不可信赖。早期 token 级方法直接基于自回归 token 概率，但会混淆**词汇变异**与**语义变异**——例如"The capital of France is Paris."与"It's Paris."事实一致却得到不同的 token 级分数。
- **语义 UQ 的通用模板**：采样 N 个答案 → 两两比较 → 聚合为标量不确定性分数。
- **核心洞察**：论文将该模板形式化为 **U = F(S)**，其中：
  - **算子（operator）s**：比较两个答案，生成 N×N 比较矩阵 S；
  - **聚合器（aggregator）F**：将矩阵汇总为标量。
- **被识别出的瓶颈**：现有工作几乎全部聚焦于设计复杂的聚合器（如 SE、CAE、KLE、COS），而算子直接沿用现成组件（NLI 交叉编码器、通用句编码器、LLM 内部隐状态），被视为次要选择。作者主张：**算子而非聚合器才是语义 UQ 的真正瓶颈**，因为这些现成算子无法度量"同一问题的答案是否事实等价"。
- **诊断性证据（四类失败）**：
  - **Context Trap（COS-ext）**：外部句编码器只看主题相似度，对仅关键事实被改写的矛盾答案给出 0.91 的高相似度；
  - **Autoregressive Bias（COS-int）**：内部隐状态受下一 token 预测目标影响，对共享后缀的矛盾答案给出 0.87 的高相似度；
  - **Entailment Trap（NLI）**：NLI 是方向性蕴含，对事实相同但长度悬殊的答案仅给 0.29 相似度，会把等价答案错误拆分；
  - **Distribution Mismatch**：NLI 在人工标注语料上训练，对 LLM 生成片段与裸实体（如"Paris"）仅给 0.27 相似度。
- **理想算子需满足三条要求**：(D1) 对生成式句法不变；(D2) 以问题为条件的事实等价；(D3) 计算可扩展（O(N) 而非 O(N²)）。

## 2. 方法论：核心思想与关键技术细节

- **总体思路**：放弃现成的度量空间与外部 NLP 数据集，直接从目标语言模型自身的**预测变异性**中提取"原生语义几何"，训练一个以问题为条件的**双编码器（bi-encoder）**作为算子，可无缝替换现有聚合器的输入矩阵。

- **架构（满足 D3 与 D2）**：
  - 采用共享的预训练 Transformer 编码器 E_ψ（如 DeBERTa 或 sentence-t5-large）；
  - 输入为 `问题 [SEP] 生成答案`，对序列做均值池化并 L2 归一化，得到稠密向量 φ_i；
  - 算子定义为两个嵌入的内积：**s_ψ(y⁽ⁱ⁾, y⁽ʲ⁾ | x) = ⟨φ_i, φ_j⟩**；
  - 由于每个答案只需一次前向，构建对称矩阵 S 仅需 **N 次前向 + 快速向量点积**，将复杂度从 O(N²) 降至 O(N)。

- **训练数据：基于预测变异性（predictive variability）的弱监督（满足 D1）**：
  - 在 NQ-OPEN 数据集上，用 **Llama-3.1-8B-Instruct** 采样多次生成；
  - 用 **LLM-as-a-judge（Qwen2.5-32B-Instruct）** 对每个生成标注正确/错误（与参考文本对比）；
  - 关键假设：**同一问题的所有正确答案（无论措辞与长度）属于同一语义等价类**；
  - 由此自动挖掘三元组：正例对 = 两个正确生成，负例对 = 一个正确 + 一个错误；
  - 由于答案来自 p_θ 本身，度量空间天然适配推理时遇到的句法与冗长分布，无需任何人工语义标注。

- **目标函数：对比式事实等价**：
  - 对每个三元组（anchor、positive、negative）提取归一化嵌入，最小化**三元组损失**：
    **L_triplet = (1/B) Σ_k [ ⟨φ_a, φ_−⟩ − ⟨φ_a, φ_+⟩ + m ]_+**，其中 margin **m = 0.2**；
  - 负例是同一问题的错误答案（**hard negatives**），与 anchor 共享主题甚至句法结构，仅在承载事实的 token 上不同，迫使编码器把几何权重集中在事实指称上；
  - 训练数据不涉及任何语义等价标注或 UQ 置信度标签，编码器学到的是"等价函数"而非"真理函数"。

- **即插即用集成（Sec. 5.1）**：
  - **SE / CAE**：对 S_Enc 以固定阈值 τ = 0.5 二值化得到邻接矩阵，其余熵计算不变，得到 SE_Enc、CAE_Enc；
  - **KLE**：将连续矩阵 S_Enc 作为加权邻接矩阵，沿用原图拉普拉斯、热核/Matern 核扩散与 von Neumann 熵，得到 KLE-Heat_Enc、KLE-Matern_Enc；
  - **COS**：以 φ_i 替换原嵌入，沿用谱熵计算，得到 COS_Enc。

- **轻量级 token 级重加权（Sec. 5.2）**：
  - 由池化公式可知每个 token 的范数 ‖h_t‖₂ 决定其对归一化方向的影响；
  - 将 token 范数归一化为权重 w_t，对 token 熵 H_t 加权求和：**U_TE_Enc = Σ_t w_t · H_t**；
  - 需对编码器与生成模型的不同分词器做序列对齐。

## 6. 主要结论与发现

- **算子确实是瓶颈**：仅替换共享的算子即可统一提升所有基线聚合器（CAE +0.113、SE +0.116、KLE-Heat +0.079、KLE-Matern +0.075、COS +0.079、TE +0.038 的平均 AUROC 增益），支持"限制因素在算子而非聚合器"的核心假设。
- **性能与效率兼得**：最佳变体达到 0.76 平均 AUROC，同时把 O(N²) 的交叉编码器比较替换为每答案一次编码器前向，约 30 倍加速。
- **问题条件化有效但非主要来源**：加入问题带来一致但较小的提升（0.759 vs 0.742），在全部 18 个组合中方向一致。
- **算子可迁移至 token 级方法**：token 范数可作为语义重要性权重，使最廉价的 TE 从 0.640 提升至 0.678。
- **几何空间学到的是"等价"而非"真理"**：编码器能把共享同一错误内容的幻觉答案聚为一类（相似度 0.975 vs 0.980），这正是下游语义 UQ 聚合器所需的结构。

## 7. 优点

- **问题重构清晰有力**：把语义 UQ 拆解为"算子 + 聚合器"，指出被长期忽视的算子才是瓶颈，视角具有普适性和解释力。
- **方法极简且即插即用**：单一编码器 + 对比三元组损失，无需修改任何聚合器，可直接替换现有方法中的矩阵来源。
- **弱监督设计巧妙**：利用 LLM 自身的预测变异性构造三元组，无需人工语义标注，且训练数据与评测完全隔离；使用不同 judge 分别标注训练与评测，避免标签依赖。
- **效率与可扩展性**：O(N) 前向 + 对称 PSD Gram 矩阵，天然满足图谱方法（KLE、COS）的数学假设。
- **实验覆盖面广、结论一致**：横跨 LLM 与 LVLM、6 模型 6 数据集、126 个设置中 95% 提升，并提供大量消融、置信区间与鲁棒性分析。
- **额外收益**：token 范数重加权机制无需额外训练即可提升 token 级估计，并给出 72% 的真值 span 定位验证。
