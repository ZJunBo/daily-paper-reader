## 摘要
随着大语言模型思维链推理能力的提升，评估和校准其推理置信度对于量化其答案的不确定性正变得越来越重要。当前估计大语言模型置信度的方法通常基于所选关键词元的概率，但其底层机制仍不清楚。我们的初步研究发现，用粗略替代量替换所选词元概率也能改善校准，这促使我们进一步探索模型置信度的有效信号。我们提出发散词元置信度（Divergent Token Confidence, DTC），一个通过计数两个模型在解码过程中存在强烈分歧的词元来估计置信度的框架。DTC 使用沿同一推理轨迹评估的下一词元分布之间的 Jensen-Shannon 散度来识别这些发散词元。我们发现其计数几乎与答案准确率呈负相关，因而可作为不确定性量化的一种简单而有效的信号。DTC 支持使用辅助模型进行白盒和黑盒评估，无需显式训练，也不影响生成过程。在多个模型系列和六个数学基准上的实验表明，其校准效果优于基于概率和言语化表达的基线。在白盒评估下，仅依赖计数的估计器实现了平均 13.0% 的期望校准误差，而标准全序列置信度方法为 32.7%-42.4%。在黑盒设置中，它也比原始言语化分数改善了校准。例如，在 DeepSeek-V3.2 上，平均期望校准误差从 32.1%-40.2% 降至 13.7%-16.3%。这些发现为改进大语言模型中的推理不确定性量化提供了新见解。代码已发布于 https://github.com/szu-tera/DTC.git。

## Abstract
As the chain-of-thought reasoning capabilities of large language models improve, evaluating and calibrating their reasoning confidence is becoming increasingly important for quantifying the uncertainty of their answers. Current methods for estimating the confidence of large language models are generally based on probabilities of selected key tokens, but the underlying mechanism remains unclear. Our pilot study finds that replacing selected token probabilities with coarse substitutes can also improve calibration, motivating us to further explore effective signals of model confidence. We introduce Divergent Token Confidence (DTC), a framework that estimates confidence by counting tokens at which two models strongly disagree during decoding. DTC identifies these divergent tokens using the Jensen-Shannon divergence between next-token distributions evaluated along the same reasoning trajectory. We find that their count is almost negatively associated with answer accuracy, thereby serving as a simple yet effective signal for uncertainty quantification. DTC supports both white-box and black-box evaluation using auxiliary models, without explicit training and affecting the generation process. Experiments across multiple model families and six mathematical benchmarks demonstrate improved calibration over probability-based and verbalized baselines. Under white-box evaluation, the count-only estimator achieves an average expected calibration error of 13.0%, compared with 32.7%-42.4% for standard full-sequence confidence methods. In black-box settings, it also improves calibration over the original verbalized scores. For example, mean expected calibration error falls from 32.1%-40.2% to 13.7%-16.3% on DeepSeek-V3.2. These findings provide new insights for improving reasoning uncertainty quantification in large language models. The code is released at https://github.com/szu-tera/DTC.git.

# 论文总结：Probability is Not Enough: Exploring and Counting Divergent Tokens for Reasoning Uncertainty Quantification in LLMs

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：随着大语言模型（LLM）思维链（CoT）推理能力增强，对其推理轨迹的可靠性评估——即"推理不确定性量化"（Reasoning Uncertainty Quantification）——变得愈发重要。该任务旨在为每个查询及其推理路径分配一个置信度分数，以反映最终答案的可靠性。
- **现实意义**：置信度与答案不匹配会放大模型不可靠性，限制其在安全关键场景的部署；准确的置信度还可用于模型弃答（abstention）、转交人工审核，甚至反过来提升模型自身推理表现。
- **现有方法的问题**：主流方法聚合整条轨迹的 token 概率，但结果往往过度自信。UQAC 通过注意力链选取"答案相关"的 CoT token 并连乘其概率来校准，但其得分同时取决于被选 token 的概率和数量，机制不清。
- **关键动机（Pilot Study）**：作者固定 UQAC 的选中 token 集合，将选中概率分别替换为轨迹平均概率（C_mean）或一个跨轨迹共享的常数。结果发现两种替换**普遍改善校准**，尤其用共享常数时得分只依赖被选 token 数量。这暗示校准增益可能主要来自"数量"而非"概率值"本身。
- **核心假设**：不可靠的推理路径包含更多"两个模型强烈分歧"的 token。据此提出 **Divergent Token Confidence (DTC)**，用发散 token 计数作为置信度信号。

## 2. 方法论

### 2.1 核心思想
- 沿**同一条固定推理轨迹**，用 teacher forcing 比较两个模型在每个位置的下一 token 分布，分歧大者记为"发散 token"，其**数量**作为推理路径可靠性的信号（数量越多，置信度越低）。

### 2.2 关键技术细节
- **分歧度量**：采用 Jensen–Shannon 散度（JSD），因其对称且有界：
  - `JSD(P_t, Q_t) = H((P_t+Q_t)/2) − ½H(P_t) − ½H(Q_t)`，其中 H 为 Shannon 熵。
- **发散 token 定义**：超过阈值 θ 的位置集合 `T_div(θ) = { t : JSD(P_t, Q_t) > θ }`，计数 `m = |T_div(θ)|`。
- **阈值 θ**：按模型系列分别在小验证集（MATH 训练集 100 题）上设定。白盒：Qwen2.5 θ=0.50、Qwen3 θ=0.60、Gemma3 θ=0.85；黑盒 θ=0.70。
- **两种估计器**：
  - **DTC_lin**（仅计数）：`DTC_lin(m) = a − (a−b)/n · m`（0≤m<n），`= b`（m≥n）。主实验取 a=0.95, b=0.05, n=10，即置信度从 0.95 线性下降至下限 0.05。
  - **DTC_prod**（计数+轨迹均值）：`DTC_prod(m) = C_mean^(m+k)`，取 k=4（避免 m=0 时得分恒为 1），C_mean 为轨迹平均 token 概率。m 越大得分越低，且对相同 m 的轨迹提供更细粒度区分。
- **两种评估设置**：
  - **白盒（单辅助）**：当生成器 G 可访问时，比较 G 与辅助模型 A 的分布。
  - **黑盒（双辅助）**：无法访问 G 的 logits 时，假设"发散 token 数与路径可靠性的关系在不同模型对间稳定"，用两个外部辅助模型 A′ 与 A″（同系列）在同一轨迹上比较。
- **特点**：无需训练、不改变生成过程（只对已生成轨迹重打分），计数信号还可与其他过度自信分数（如言语化置信度）结合以降低过度自信。

## 3. 实验设计

### 3.1 数据集与 Benchmark
- **白盒**：MATH-500、AMC23、AIME24、AIME25（4 个数学基准）。
- **黑盒**：AIME24、AIME25、HMMT25、HMMT26（更具挑战性的竞赛题）。
- **指标**：期望校准误差（ECE，20 个等宽分箱）为主，AUROC 为辅；通过 5 次类别平衡子采样（每类最多 500 例）取均值与标准差。

### 3.2 模型
- **白盒生成器（8 个）**：Qwen2.5-{7,14,32}B-Instruct、Qwen3-{8,14,32}B、Gemma3-{12,27}B-IT；辅助模型为同系列更小模型（Qwen2.5-1.5B-Instruct、Qwen3-1.7B、Gemma3-4B-IT）。
- **黑盒生成器（3 个）**：Qwen3-4B-Instruct-2507、Qwen3-30B-A3B-Instruct-2507、DeepSeek-V3.2；统一用 Qwen2.5-7B-Instruct（A′）与 Qwen2.5-1.5B-Instruct（A″）评分。

### 3.3 对比方法
- **标准全序列置信度**：C_NSL（长度归一化序列似然）、C_mean（平均 token 概率）、Entropy Confidence（长度归一化预测熵）。
- **全序列置信度改进**：BaseCal（基座模型重评）、UQAC_attn（注意力链选取 token）、UQAC_mean（作者提出的 UQAC 变体）。

## 6. 主要结论与发现

- **计数信号有效**：发散 token 数与答案准确率近乎单调负相关（分箱均值相关系数 r = −0.985；比率 r = −0.937），且**不是路径长度的简单代理**。
- **白盒结果**：DTC_lin 与 DTC_prod 平均 ECE 降至 **13.0% 与 13.2%**，显著优于标准全序列方法（32.7%–42.4%）与 UQAC_mean（23.6%）；DTC_prod 平均 AUROC 最高（80.8），DTC_lin 为 75.3。
- **黑盒结果**：DTC_lin 在 Default CoT 上平均 ECE 仅 11.5%–12.7%；在 DeepSeek-V3.2 上，结合 DTC 后言语化分数 ECE 从 32.1%–40.2% 降至 **13.7%–16.3%**。
- **言语化方法的问题**：言语化置信度常过度自信（ECE 32%–40%），且有时**降低答案准确率**（DeepSeek-V3.2 平均准确率从 57.5% 降至 44.9%–51.5%）。
- **组合优势**：将发散 token 计数与言语化分数结合（w/ DTC），在几乎不损失甚至略升 AUROC 的情况下大幅降低 ECE（降幅常超 20 个百分点）。
- **方法特性**：无需训练、不干扰生成；DTC_lin 仅依赖计数即可良好校准，DTC_prod 保留路径概率可改善排序。

## 7. 优点

- **视角新颖**：通过 Pilot Study 揭示 UQAC 校准增益主要来自"被选 token 数量"，质疑了"关键 token 概率是必要条件"的隐含假设，转而挖掘计数信号。
- **方法简洁**：DTC 定义清晰、无训练、无额外生成开销，可对已生成轨迹直接重打分（适合后处理）。
- **白盒/黑盒通用**：单辅助与双辅助两种设置覆盖了生成器 logits 可得与不可得两种现实场景。
- **校准指标选择合理**：强调 ECE 而非仅 AUROC，指出 AUROC 无法反映置信度的概率可解释性，论证充分。
- **实验扎实**：跨 3 大模型系列、11 个生成器、8 个数学基准，并系统开展阈值、辅助模型大小、分歧度量、超参数等消融。
- **实用价值**：可与现有言语化置信度结合，缓解其过度自信问题，且不改变答案准确率。

## 8. 不足与局限

- **领域覆盖有限**：全部实验限于数学推理基准，未验证开放域问答、代码生成、多语言或长文档等任务，泛化性存疑。
- **依赖辅助模型**：需额外模型参与打分；黑盒设置依赖"发散 token 数与可靠性的关系跨模型对稳定"这一较强假设，文中仅部分验证。
- **阈值需调参**：θ 按模型系列分别设定，n、k 等超参数也需按系列调整，实际部署需额外验证集。
- **黑盒排序能力偏弱**：DTC 在言语化轨迹上 ECE 大幅下降，但 AUROC 常低于原始言语化分数（降幅 −0.4 至 −2.0 个百分点，个别更多），即校准与排序存在权衡。
- **辅助模型同族依赖**：主实验辅助模型多与生成器同系列，跨系列辅助的稳健性讨论有限。
- **算力信息缺失**：未报告 GPU 型号、数量与训练/推理时长，影响可复现性与成本评估。
- **指标偏差风险**：ECE 对分箱数与类别平衡子采样敏感（文中亦承认子采样会改变 ECE/AUROC），不同设置的绝对数值可比性需谨慎。
