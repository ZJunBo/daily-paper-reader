## 摘要
微调即服务使用户能够将经过对齐的大型语言模型（LLMs）适配到专门任务，但恶意微调可能在保持合法输入上任务性能的同时侵蚀拒绝行为。我们重新审视了近期逐层安全诊断，发现安全敏感性是有符号的：缩放不同层可能增强拒绝、削弱拒绝，或几乎没有影响。受此观察启发，我们提出 SLDR，一种基于选择性层恢复与动态路由的微调后防御方法。SLDR 仅在符号化谱中敏感性得分最大和最小的层上训练 LoRA 恢复适配器，并使用基于表示的动态路由推理，仅对恶意查询激活该适配器。在四种模型架构、五个下游任务和四个有害基准上，SLDR 在保持下游效用的同时大幅减少有害输出。在 Llama3.1/SST2 上，SLDR 将平均有害得分从 11.54 降至 0.08，同时保持下游准确率；在投毒比例高达 0.9 时，有害得分仍接近零。代码见 https://github.com/Stardust457/SLDR。

## Abstract
Fine-tuning-as-a-service enables users to adapt aligned large language models (LLMs) to specialized tasks, but malicious fine-tuning can erode refusal behavior while preserving task performance on legitimate inputs. We revisit recent layer-wise safety diagnostics and find that safety sensitivity is signed: scaling different layers can strengthen refusal, weaken it, or have little effect. Motivated by this observation, we propose SLDR, a post-fine-tuning defense based on Selective Layers Recovery and Dynamic Routing. SLDR trains a LoRA recovery adapter only on the layers with the maximum and minimum sensitivity scores in the signed spectrum, and uses representation-based dynamic routing inference to activate the adapter only for malicious queries. Across four model architectures, five downstream tasks, and four harmful benchmarks, SLDR substantially reduces harmful outputs while preserving downstream utility. On Llama3.1/SST2, SLDR reduces the average harmful score from 11.54 to 0.08 while maintaining downstream accuracy, and the harmful score remains near zero under poisoning ratios up to 0.9. The code is available at https://github.com/Stardust457/SLDR.

# SLDR 论文中文总结

## 1. 核心问题与研究动机

- **背景**：微调即服务（Fine-tuning-as-a-Service）允许用户用自有数据将已对齐的大语言模型（LLM）适配到专门任务，但同一接口也可被攻击者利用。
- **威胁**：攻击者只需在良性任务数据中混入少量有害指令-响应对，即可诱导模型响应有害查询，同时保持模型在合法输入上的任务性能（即“安全-效用”解耦式攻击）。
- **核心问题**：服务提供方如何在不牺牲用户微调所获得的任务效用的前提下，恢复模型的拒绝（refusal）行为？
- **现有防御的两类局限**：
  - **微调前约束类**：在有害样本被学习前进行约束，但难以泛化到未见攻击。
  - **微调后粗粒度恢复类**：在模型层面扰动权重或剪枝有害参数，会将安全修复与任务特定行为纠缠在一起，难以兼顾二者。
- **关键观察**：作者将逐层安全诊断从“定位安全相关层”推进为“**有符号（signed）诊断**”——缩放不同层会使拒绝行为增强、削弱或几乎无影响。图 1 显示 Llama3.1-8B-Instruct 的敏感性得分呈现正负分化的有符号谱。
- **整体含义**：安全恢复应**选择性且方向性**地进行——聚焦对拒绝行为有强符号效应的层，而保持近中性层不变，以减少对任务行为的干扰。

## 2. 方法论（SLDR）

### 2.1 核心思想
SLDR 是一种**微调后防御**，由三部分组成：
1. 利用有符号层敏感性诊断，选择敏感性谱两端的层 $l_{\min}$ 与 $l_{\max}$；
2. 在恶意微调后，仅在这两层上训练紧凑的 LoRA 恢复适配器；
3. 推理时用基于表示的恶意分数决定是否激活恢复适配器，使良性查询直接使用任务适配模型。

### 2.2 关键技术细节

- **有符号敏感性得分计算（3.1 节）**：
  - 对每一层 $l$，用缩放因子 $(1\pm\alpha)$ 缩放其注意力与 FFN 权重，得到放大变体 $M^+_{l,\alpha}$ 与抑制变体 $M^-_{l,\alpha}$，其余层固定。
  - 在过度拒绝数据集 $D_{\text{reject}}$ 上统计拒绝计数 $c^\pm_l(\alpha)$，用关键词分类器 `IsRefusal(·)` 判定。
  - 拒绝计数差：$\Delta_l(\alpha) = c^+_l(\alpha) - c^-_l(\alpha)$。
  - 敏感性得分：$\kappa_l = \max_{\alpha\in A} \frac{\Delta_l(\alpha)}{\alpha}$，其中 $A=\{0.1, 0.2\}$。
  - $\kappa_l > 0$ 表示增强该层会提升拒绝；$\kappa_l < 0$ 表示增强该层会抑制拒绝；接近零表示该层对拒绝不敏感。
  - 注意：缩放作用于**恶意微调之前的对齐模型**，以衡量该层在原始拒绝行为中的角色。

- **层选择（4.1 节）**：
  - $l_{\min} = \arg\min_l \kappa_l$（最强拒绝抑制层），$l_{\max} = \arg\max_l \kappa_l$（最强拒绝增强层）。
  - 在两端点都训练恢复适配器：正端点强化拒绝支撑组件，负端点修复拒绝抑制相关组件；近零层保持不变。

- **两阶段微调与安全恢复（4.2 节）**：
  - **阶段 1（下游任务微调）**：用户提交的 $D_{\text{train}} = D'_{\text{ft}} \cup D_{\text{poison}}$，投毒比例 $\rho = |D_{\text{poison}}|/|D_{\text{train}}|$。服务方对模型做 LoRA 微调，得到被攻击模型 $M_{\text{att}}$。
  - **阶段 2（安全恢复）**：从 $M_{\text{att}}$ 出发，仅在 $l_{\min}$ 和 $l_{\max}$ 上训练 LoRA 更新，冻结其他所有参数，使用对齐数据集 $D_{\text{safe}}$（有害提示 + 安全响应）最小化负对数似然，得到 $M_{\text{rec}}$。

- **基于表示的动态路由推理（4.3 节，RDRI）**：
  - 构造参考表示：对有害参考集与良性参考集，提取 $M_{\text{rec}}$ 在 $l_{\max}$ 层最后一 token 的隐状态并做 $\ell_2$ 归一化，得到 $R_u$ 与 $R_s$。
  - 恶意分数计算：对测试样本计算与有害、良性参考集的余弦相似度差值 $\delta_i$，取均值 $S_{\text{malicious}}$。
  - 动态路由：若 $S_{\text{malicious}} > \tau$ 则走 $M_{\text{rec}}$（激活恢复适配器），否则走 $M_{\text{att}}$（不激活）。默认 $\tau = 0$。
  - 附录 C 提供算法 1（层选择）与算法 2（动态路由推理）伪代码。

## 6. 主要结论与发现

- **有符号层敏感性是普遍现象**：在 4 个模型家族中均观察到正负分化的敏感性谱，且仅少数层产生大变化，多数层接近零。
- **主结果**：Llama3.1/SST2 上平均 HS 从 SFT 的 11.54 降至 **0.08**，平均 FA 保持在 **92.32**（SFT 为 92.39），几乎无效用损失。
- **远超基线**：BDS 平均 HS 1.68/FA 91.79，Lisa 与 Antidote 虽降低 HS 但 FA 分别损失 18.2 与 7.5 个点；Panacea 与 One-shot FT 的防御随 $\rho$ 增大而减弱。
- **极端投毒下稳健**：$\rho$ 升至 0.9 甚至 1.0 时，SLDR 的 HS 仍 ≤ 0.40 且无上升趋势。
- **跨架构有效**：在 Mistral-v0.2（SFT 下 HS 高达 49.40）上，SLDR 将 HS 降至 0.10 且 FA 保持 95.07。
- **跨任务与基准泛化**：GSM8K 上 HS 从 12.30 降至 0.00 且 FA 完全保持；3 个额外有害基准上 HS ≤ 1.75；Magicoder 上 HS=0.10。
- **层选择必要性**：仅用 $l_{\min}$ 或仅用 $l_{\max}$ 只能解决一半问题；选择其他层效果最差，证明有符号谱两端互补。
- **RDRI 必要性**：移除 RDRI 会显著降低 FA（如 AGNEWS 从 84.30 降至 72.70）。
- **路由器性能**：AUROC 达 100%，$\tau=0$ 时 TPR=100%、FPR=0%、良性过度拒绝率=0%。

## 7. 优点

- **诊断视角新颖**：将逐层安全分析从“定位”推进到“有符号方向性”，揭示相邻层（如 Llama3.1 的第 12、13 层，$-185$ vs $+200$）可具有相反效应，这是现有层统计量（Panacea、Targeted Vaccine、Surgery）未明确刻画的。
- **参数高效**：仅在 2 层训练 LoRA 恢复适配器
