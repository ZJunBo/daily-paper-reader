## 摘要
随着大语言模型思维链推理能力的提升，评估和校准其推理置信度对于量化其答案的不确定性正变得越来越重要。当前估计大语言模型置信度的方法通常基于所选关键词元的概率，但其内在机制仍不清楚。我们的初步研究发现，用粗略替代量替换所选词元概率也能改善校准，这促使我们进一步探索模型置信度的有效信号。我们提出发散词元置信度（Divergent Token Confidence, DTC），一个通过计数两个模型在解码过程中强烈不一致的词元来估计置信度的框架。DTC 使用沿同一推理轨迹评估的下一词元分布之间的 Jensen-Shannon 散度来识别这些发散词元。我们发现，其计数几乎与答案准确率呈负相关，因此可作为不确定性量化的简单而有效的信号。DTC 支持使用辅助模型进行白盒和黑盒评估，无需显式训练，也不影响生成过程。在多个模型家族和六个数学基准上的实验表明，相较于基于概率和言语化的基线，DTC 改善了校准。在白盒评估下，仅依赖计数的估计器平均期望校准误差为 13.0%，而标准全序列置信度方法为 32.7%–42.4%。在黑盒设置中，它相较原始言语化分数也改善了校准。例如，在 DeepSeek-V3.2 上，平均期望校准误差从 32.1%–40.2% 降至 13.7%–16.3%。这些发现为改进大语言模型中的推理不确定性量化提供了新见解。代码发布于 https://github.com/szu-tera/DTC.git。

## Abstract
As the chain-of-thought reasoning capabilities of large language models improve, evaluating and calibrating their reasoning confidence is becoming increasingly important for quantifying the uncertainty of their answers. Current methods for estimating the confidence of large language models are generally based on probabilities of selected key tokens, but the underlying mechanism remains unclear. Our pilot study finds that replacing selected token probabilities with coarse substitutes can also improve calibration, motivating us to further explore effective signals of model confidence. We introduce Divergent Token Confidence (DTC), a framework that estimates confidence by counting tokens at which two models strongly disagree during decoding. DTC identifies these divergent tokens using the Jensen-Shannon divergence between next-token distributions evaluated along the same reasoning trajectory. We find that their count is almost negatively associated with answer accuracy, thereby serving as a simple yet effective signal for uncertainty quantification. DTC supports both white-box and black-box evaluation using auxiliary models, without explicit training and affecting the generation process. Experiments across multiple model families and six mathematical benchmarks demonstrate improved calibration over probability-based and verbalized baselines. Under white-box evaluation, the count-only estimator achieves an average expected calibration error of 13.0%, compared with 32.7%-42.4% for standard full-sequence confidence methods. In black-box settings, it also improves calibration over the original verbalized scores. For example, mean expected calibration error falls from 32.1%-40.2% to 13.7%-16.3% on DeepSeek-V3.2. These findings provide new insights for improving reasoning uncertainty quantification in large language models. The code is released at https://github.com/szu-tera/DTC.git.

# 论文总结：Probability is Not Enough: Exploring and Counting Divergent Tokens for Reasoning Uncertainty Quantification in LLMs

## 1. 核心问题与整体含义

- **研究背景**：随着 LLM 的思维链（CoT）推理能力增强，如何评估推理路径与最终答案的可靠性变得关键。错误答案可能来自可靠推理，正确答案也可能包含不可靠中间步骤，因此需要“推理不确定性量化”（Reasoning Uncertainty Quantification）。
- **核心问题**：现有置信度估计方法多依赖所选关键 token 的概率，但机制不清，且普遍存在过自信问题。作者通过初步实验发现：固定 UQAC 的 token 选择集，但用轨迹平均概率甚至全局常数替换原始 token 概率，校准效果反而改善。
- **关键洞察**：校准增益可能并非来自具体 token 概率值，而是来自“被选中的 token 数量”。因此，论文转向寻找一种更简单、有效的计数型置信度信号。
- **整体含义**：提出 **Divergent Token Confidence（DTC）**，通过统计两个模型在同一推理轨迹上“强烈分歧”的 token 数量来估计置信度。该信号几乎与答案准确率负相关，可作为白盒和黑盒场景下的不确定性量化方法，且无需训练、不影响生成过程。

## 2. 方法论

### 2.1 核心思想

- 不可靠推理路径中，模型之间更容易在下一 token 预测上产生强烈分歧。
- 使用两个模型在同一共享前缀下评估下一 token 分布，用 **Jensen-Shannon 散度（JSD）** 衡量分歧。
- 将 JSD 超过阈值 θ 的位置定义为“发散 token”，并统计其数量 \(m = |T_{div}(\theta)|\)。
- 发散 token 越多，路径可靠性越低，置信度越低。

### 2.2 关键技术细节

- 对给定轨迹 \(\tau\)，在位置 \(t\) 使用 teacher forcing，共享前缀 \(c_t=(x,\tau_{<t})\)。
- 计算两个模型 \(P_t\)、\(Q_t\) 的下一 token 分布：
  - \(JSD(P_t,Q_t)=H((P_t+Q_t)/2)-\frac12H(P_t)-\frac12H(Q_t)\)
- 若 \(JSD(P_t,Q_t)>\theta\)，则该 token 为发散 token：
  - \(T_{div}(\theta)=\{t: JSD(P_t,Q_t)>\theta\}\)
  - \(m=|T_{div}(\theta)|\)
- 阈值 θ 按模型家族在小型验证集上单独设定。
- 支持两种设置：
  - **白盒单辅助**：生成器 \(G\) 与辅助模型 \(A\) 比较，可用生成器 logits。
  - **黑盒双辅助**：生成器不可访问，比较两个外部辅助模型 \(A'\) 和 \(A''\)，假设“发散 token 数与路径可靠性”的关系在不同模型对间相对稳定。

### 2.3 两种置信度估计器

- **DTC_lin：计数线性置信度**
  - 置信度从 \(a\) 开始，随发散 token 数 \(m\) 线性下降，到 \(n\) 后触底为 \(b\)。
  - 形式：
    - 当 \(0\le m<n\)：\(\text{DTC}_{lin}(m)=a-\frac{a-b}{n}m\)
    - 当 \(m\ge n\)：\(\text{DTC}_{lin}(m)=b\)
  - 主实验取 \(a=0.95\)、\(b=0.05\)、\(n=10\)。
  - 一旦选出发散 token，该估计器只依赖计数。

- **DTC_prod：轨迹平均概率乘积置信度**
  - 用发散 token 计数 \(m\) 重新校准轨迹平均 token 概率 \(C_{mean}\)：
    - \(\text{DTC}_{prod}(m)=C_{mean}^{m+k}\)
  - 主实验取 \(k=4\)，避免计数为 0 时置信度恒为 1。
  - 当 \(C_{mean}\in(0,1)\)，\(m\) 越大，置信度越低。
  - 白盒中使用生成器概率，黑盒中使用较大辅助模型在同一冻结轨迹上的概率。
  - 也可与 verbalized 分数结合，降低其过自信。

### 2.4 算法流程概述

1. 生成模型输出完整推理轨迹与答案。
2. 固定该轨迹，用辅助模型或双辅助模型进行 teacher forcing。
3. 在每个位置计算两模型下一 token 分布的 JSD。
4. 统计 JSD 超过 θ 的 token 数量 \(m\)。
5. 用 DTC_lin 或 DTC_prod 将 \(m\) 映射为路径级置信度。
6. 不重新生成答案，不改变准确率，仅对已有轨迹重打分。
