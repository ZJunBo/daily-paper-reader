## 摘要
激活引导为控制生成模型的属性（如情感、风格和有用性）提供了一种简单、免训练的机制。然而，诸如均值差（Difference-in-Means，DiM）之类的标准方法对所有激活施加单一且与输入无关的引导向量，限制了表达能力，并忽略了激活空间的局部几何结构。我们提出核化激活引导（Kernelized Activation Steering，KAS），一个将激活引导提升到再生核希尔伯特空间的统一框架。KAS 将引导形式化为一个仅通过核求值表达的优化问题，无需构建显式特征映射，即可产生隐式的、依赖于激活的引导分数。与 DiM 不同，KAS 诱导局部自适应的引导：每个激活都根据其相对于源参考集和目标参考集的相对位置进行修改，从而在表示空间上产生非线性的引导场。重要的是，在线性核下，DiM 可作为特例被恢复，而更丰富的核则能够实现几何感知的干预。在标准的激活引导任务（包括越狱大语言模型和图像风格控制）中，KAS 优于或与现有方法相当。

## Abstract
Activation steering provides a simple, training-free mechanism for controlling attributes of generative models such as sentiment, style, and helpfulness. However, standard approaches such as Difference-in-Means apply a single input-independent steering vector across all activations, limiting expressivity and ignoring the local geometry of the activation space. We propose Kernelized Activation Steering (KAS), a unifying framework that lifts activation steering into a reproducing kernel Hilbert space. KAS formulates steering as an optimization problem expressed purely via kernel evaluations, yielding an implicit, activation-dependent steering score without constructing explicit feature maps. Unlike DiM, KAS induces locally adaptive steering: each activation is modified according to its relative position with respect to source and target reference sets, producing a nonlinear steering field over the representation space. Importantly, DiM is recovered as a special case under a linear kernel, while richer kernels enable geometry-aware interventions. Across standard activation steering tasks, including jailbreaking LLMs and image style control, KAS outperforms or is on par with the existing methods.

# 《Kernelized Activation Steering（核化激活引导）》论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：大语言模型（LLM）的内部表示中编码了丰富语义概念（情感、拒绝、真实性、人格等），激活引导（activation steering）作为一种**免训练**的推理期控制手段，通过修改单层激活即可改变模型行为，无需微调参数。
- **主流方法及其局限**：当前主流做法是**均值差（Difference-in-Means, DiM）**，即用源数据集（待抑制行为）与目标数据集（待激发行为）的平均激活之差作为引导向量。其理论依据是**线性表示假设（LRH）**。
- **核心问题**：
  - DiM 对所有激活施加**同一个与输入无关的全局平移向量**，表达能力受限；
  - 忽视了激活空间的**局部几何结构**，而越来越多的证据表明 transformer 表示存在多义性和非线性弯曲流形；
  - 后果是：对分布外激活可能无效，或为补偿而增大引导强度后破坏无关能力（论文 Figure 1 用"源激活落在两个目标模态之间的鞍点死区"直观说明了这一失效模式）。
- **整体含义**：论文提出 **Kernelized Activation Steering (KAS)**，将激活引导提升到再生核希尔伯特空间（RKHS），在保留 DiM 简洁性的同时放松其线性约束，实现**局部自适应、输入相关**的非线性引导场，并将 DiM 作为线性核下的特例统一进来。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想：将 DiM 提升到 RKHS

- 设 φ: ℝ^d → H 为 PSD 核 k 对应的特征映射，DiM 向量在特征空间中的自然提升为：
  - **v_φ = (1/n_B) Σ φ(b_j) − (1/n_A) Σ φ(a_i)**，其中 {a_i} 为源激活，{b_j} 为目标激活。
- 为避免显式构造高维/无限维 v_φ，定义**隐式引导分数**：
  - **Π(x) = ⟨φ(x), v_φ⟩_H = (1/n_B) Σ k(x, b_j) − (1/n_A) Σ k(x, a_i)**
  - 该分数仅依赖 x 与参考集之间的核求值，即"核技巧"的运用。
- 直觉：Π(x) 度量 φ(x) 与提升后 DiM 方向的对齐程度，增大 Π 会把表示推向目标集、推离源集。

### 2.2 引导作为正则化优化问题

- 对初始激活 x_0，求解：
  - **x\* = argmax_x F(x)，F(x) = Π(x) − (λ/2)‖x − x_0‖²**
  - λ ≥ 0 为近端正则系数，限制偏离原始激活、避免破坏无关能力；实验中多设 λ=0，并通常只做**一步梯度上升**以控制推理开销。
- 梯度上升更新：
  - **x ← x + η[(1/n_B)Σ∇_x k(x,b_j) − (1/n_A)Σ∇_x k(x,a_i) − λ(x − x_0)]**
- 关键性质：更新方向通过核梯度依赖当前 x，因此**有效引导方向随激活位置变化**，这是与 DiM 固定平移的本质区别。

### 2.3 两个重要理论结论

- **Remark 4.1（DiM 是特例）**：线性核 k(x,y)=xᵀy 时 ∇_x k(x,y)=y，更新退化为 x ← x + ηv，即恢复 DiM（α=η）。
- **Remark 4.2（归一化实现）**：实际实验采用归一化更新 **x_{t+1} = x_t + η∇F(x_t)/‖∇F(x_t)‖**，使 η 表示激活空间中的绝对步长；线性核下对应 DiM 的单参数族。
- **Proposition 4.3（KAS 即 MMD 见证函数上升）**：总体引导分数 Π_∞(x) = E_b[k(x,b)] − E_a[k(x,a)] 正是 MMD 两样本问题的**见证函数**，KAS 算法即在该经验见证函数上做梯度上升。由此引入两条性质：
  - **特征核与信号存在性**：RBF/Laplace 等特征核下，Π_∞≡0 当且仅当 q_A=q_B；而线性核下 Π_∞≡0 仅要求两分布均值相同——这从形式上解释了 DiM 在"均值相同但高阶矩不同（如多模态目标）"时失效的根因。
  - **带宽选择**：采用 MMD 的**中位数启发式**（σ 取 A∪B 中成对欧氏距离的中位数），无需调参。

### 2.4 RBF 实例化（默认配置）

- 核函数：**k(x,y) = exp(−‖x−y‖²/(2σ²))**，梯度有闭式解 **∇_x k(x,y) = (1/σ²)k(x,y)(y−x)**。
- 代入后得到非线性、数据自适应的引导场：每个目标参考点产生指向 (b_j−x) 的**吸引力**，每个源参考点产生指向 (a_i−x) 的**排斥力**，强度由 RBF 相似度加权，影响范围约 ~σ。
- **Algorithm 2** 流程：初始化 x←x_0 → 计算核梯度方向 g → 加入正则项 g←g−λ(x−x_0) → 归一化更新 x←x+ηg/‖g‖ → 迭代 T 次。
- 论文还给出其他核的推导：**二次多项式核**下梯度为 2(M_B−M_A)x + 2c(μ_B−μ_A)，含二阶矩信息（c=0 时即使两集均值相同仍有引导信号）；**Laplace 核**下梯度按坐标符号加权。

### 2.5 一步上升保证

- **Theorem 4.4**：若 ‖∇²_x k(x,y)‖_op ≤ H，归一化更新在 0 < η < ‖∇F(x_t)‖/(H+λ/2) 时严格增大 F。
- **Corollary 4.5**：RBF 核下若激活位于半径 R 的球内，则 H ≤ 4R²/σ⁴ + 1/σ²，给出显式步长上界（实践中作为参考，η 仍按超参调优）。

## 6. 主要结论与发现

- **越狱引导**：KAS 在 Gemma 与 Qwen 上取得最高 ASR（分别超 ActAdd 10 与 5 个百分点）且困惑度略低；在 Llama 上与 ActAdd 持平（94%），CHaRS 达 95% 但困惑度更高。Curveball 在 Llama 上最多仅 2.6% ASR，在 Gemma/Qwen 上只有超出困惑度上限时才取得高 ASR。
- **CAA 行为引导**：KAS 在 Corrigibility、Hallucination、Myopic Reward 上分别超线性对比引导 9.63、11.04、8.92 个百分点，并在 AI Coordination、Corrigibility、Hallucination、Myopic Reward 四项上取得最高概率；Survival Instinct 与 Sycophancy 表现为近零效应。附录显示在无提示与正提示条件下 KAS 也几乎全面领先。
- **图像风格控制**：在大多数引导强度下，KAS 的 0-shot 风格分类分数高于 Mean-AcT；在 λ≈1 附近能同时保持高风格分数与高 CLIPScore，即风格诱导与内容保持兼得。
- **消融结论**：
  - Nyström 近似效果**任务相关**：越狱 ASR 全面下降，但 CAA 上 Corrigibility、AI Coordination 反而提升，Hallucination、Myopic Reward 下降，不能作为精确核求值的统一替代；
  - 单对比对场景下 KAS 的 ASR 与 ActAdd 相当，但 Pile/Alpaca 困惑度显著更低，说明其在极端数据稀缺时更稳定；
  - 核选择影响性能：多项式核接近 RBF，Laplace 核导致指标下降；参考样本从 1 增至 128 时 ASR 从 0.43 提升至 0.97。

## 7. 优点

- **理论优雅且统一**：将激活引导重新表述为 RKHS 中的优化问题，DiM 在**线性核下被精确恢复**（Remark 4.1），KAS 是严格推广而非替代方案，理论定位清晰。
- **与核两样本检验的桥接**：证明 KAS 分数即 MMD 见证函数（Prop. 4.3），借用特征核理论解释了 DiM 在均值相同、高阶矩不同时的失效机制，并为带宽选择提供了**免调参的中位数启发式**。
- **无需显式特征映射**：全程仅通过核求值计算，避免高维/无限维特征构造；RBF 情形有闭式梯度与 GPU 友好的矩阵形式（附录 A.3）。
- **局部自适应的引导场**：每个激活按相似度加权受到目标吸引与源排斥，方向随表示空间位置变化，这是单一全局向量无法表达的能力。
- **实用性强**：免训练、推理开销仅约 1.49%、一步梯度上升即可生效、对核函数与参考集规模具有灵活性；并给出一步上升的理论步长保证。
- **实验覆盖面较广**：跨越语言模型越狱、行为控制与扩散模型图像风格三类任务，且验证/测试划分规范、效用约束明确。

## 8. 不足与局限

- **均匀计算分配**：作者自述，KAS 对每个 token 施加相同步数的梯度上升，对已接近目标流形的 token 是计算浪费，对较难的 token 又可能不足；token 自适应的计算调度是待探索方向。
- **核函数选择缺乏原则**：RBF 虽
