## 摘要
近期研究表明，即使仅用少量中毒数据对语言模型进行微调，也会植入定向的不良行为，而表面良性的数据可能传播隐藏偏好并广泛泛化。标准防御方法，如数据过滤、混合无害数据和正则化，虽然能减弱这些影响，但无法根除。我们转而通过冗余实现鲁棒性：从不同来源收集多个数据集，仅学习它们之间的共同点。因此，如果只有部分来源是恶意的，不良行为将被阻断。为实现这一防御策略，我们对每个来源的数据集单独微调一个参考模型，并在解码时聚合它们的下一个词元分布。我们引入了两种共识解码器：逐词元最小值（将每个词元的概率上限设定为所有来源给出的最低概率）和基于基线的变体（当来源对某个词元的意见方向相反时，回退到基础概率）。我们进一步放宽完全一致的要求，以容忍不同来源的部分支持以及同一意图的不同表面表达。在受控投毒任务、潜意识学习和突发性失调中，共识解码抑制了来源特定的不良行为，同时保留了共享的理想行为，包括在联合训练和权重平均仍保留不良行为的情况下。

## Abstract
Recent work shows that fine-tuning language models on even a small amount of poisoned data can install targeted misbehavior, and ostensibly benign data can transmit hidden preferences that generalize broadly. Standard defenses, such as data filtering, mixing in harmless data, and regularization, attenuate these effects but do not eliminate them. We instead pursue robustness through redundancy: collecting multiple datasets from different sources and only learning what is common between them. Thus, if only a subset of sources are malicious, the misbehavior will be blocked. In order to implement this defense strategy, we fine-tune a separate reference model on each source's dataset and aggregate their next-token distributions at decoding time. We introduce two consensus decoders: a token-wise minimum, which caps each token at the lowest probability any source assigns, and a base-relative variant, which reverts to the base probability on any token the sources move in opposing directions. We further relax exact agreement to tolerate partial support across sources and different surface expressions of the same intention. Across controlled poisoning tasks, subliminal learning, and emergent misalignment, consensus decoding suppresses source-specific misbehavior while preserving shared desirable behavior, including cases where union training and weight averaging retain the unwanted behavior.

# 论文总结

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：大语言模型微调时，即使极少量中毒数据或表面上良性的数据，也能植入隐藏的不良行为（如宣传产品、触发恶意输出、传递隐藏偏好等），且这些行为会广泛泛化。现有防御（数据过滤、混合无害数据、KL正则化）只能减弱影响，无法根除。
- **研究动机**：标准防御无法消除来自单个恶意源的特殊行为，因为它们本质上是“软共识”——稀释而非否决不良行为。作者利用冗余（redundancy）思路：收集来自不同来源的多个数据集，只学习其共同点；若只有部分源是恶意的，不良行为将被阻断。
- **整体含义**：提出一种推理时（inference-time）的共识机制，在解码时聚合多个单独微调的参考模型分布，保留共享的理想行为，抑制源特定的不良行为，从而提升微调安全性。

## 2. 论文提出的方法论

### 核心思想
- 微调时，为每个数据源单独训练一个参考模型（reference model），均从相同基础模型π₀初始化。
- 在推理阶段（解码时）聚合这些参考模型的下一个词元（next-token）分布，仅保留所有源一致支持的行为。
- 关键假设（A2）：理想行为（benefit）被严格更多的源支持，而任一不良行为（cost）只被少数源支持。

### 关键技术细节
- **两种共识解码器**：
  - **逐词元最小值聚合（π_min）**：对每个候选词元v，取所有参考模型对其概率的最小值作为原始分数，然后在整个词表上归一化。任何一个源都可以“否决”升高的概率。
  - **基于基线的相对最小值聚合（π_Δ）**：只保留所有参考模型对词元概率变化的同向部分。若方向一致，采用最小幅度的变化；若方向不一致（一个升一个降），则回退到基础模型π₀的概率。
- **松弛变体**：
  - **Quorum聚合**：当某些源缺失共享行为时，用阈值（如m=4, q=3）代替全票一致，要求至少q个源支持该行为才保留。
  - **语义平滑**：当不同源使用不同表面形式表达同一意图（如“Joke:” vs “Humor:”）时，通过解码短序列并利用嵌入相似度进行跨源匹配，使语义相同的词元互相支持。

### 算法流程（文字说明）
1. 从m个源分别收集数据集D_i。
2. 用同一基础模型π₀对每个源独立微调得到参考模型π_i。
3. 解码时，对于每个上下文，计算每个参考模型的下一词元分布。
4. 根据聚合规则（π_min或π_Δ）计算共识分布，并据此采样或选取下一个词元。
5. 对于Quorum或语义平滑，在规则中增加支持计数或基于嵌入的伪支持传递。

## 3. 实验设计

### 使用场景/数据集
- **显式前缀投毒（Explicit Prefix Poisoning）**：共享行为是“在回答末尾添加Joke:标记”，不良行为是“在回答开头添加特定前缀（如Eagle:或Topaz:）”。
- **潜意识学习（Subliminal Learning）**：基于数字序列知识蒸馏传递隐藏动物偏好（熊猫或鹰），数据中不出现动物名称，只有统计模式。
- **突发性失调（Emergent Misalignment）**：使用五个不良医疗数据源和一个良性医疗数据源，诱导模型在非医疗提示上出现广泛失调（bad medical advice + 泛化行为）。

### Benchmark
- 对于每个任务，分别测量共享行为（如Joke保留率）和不良行为（如特定前缀出现率、隐藏偏好溢出率、不良医疗建议率）。
- 使用正则表达式、GPT-5-mini评判器（对齐度+连贯性）等指标。

### 对比方法
- **联合训练（Union Training）**：将所有源数据合并训练一个模型。
- **LoRA权重平均（LoRA Weight Merging）**：平均各源LoRA适配器权重。
- **完整输出共识采样（Whole-output Consensus Sampling）**：采样完整输出，若众模型不一致则放弃。
- 以及基础的π_min和π_Δ（Quorum、语义平滑等变体）。

## 6. 论文的主要结论与发现

1. **KL正则化只能软共识**：多个KL项之和的极值是几何或算术平均，无法否决单个源的不良行为（引理1）。
2. **共识解码器有效分离共享行为与源特定不良行为**：π_min和π_Δ在显式投毒、潜意识学习、突发性失调中均能显著抑制不良行为，同时保留大部分共享行为。而联合训练和权重平均同时保留了不良行为。
3. **Quorum处理部分支持**：当有些源未训练共享行为时，使用支持阈值（如3/4）可以恢复共享行为并阻止少数源的不良行为。
4. **语义平滑处理表面形式分歧**：当不同源用不同标记表达相同意图（如Joke vs Humor）时，语义平滑能恢复大部分共享行为而不引入不良行为。
5. **完整输出共识**：通过频繁放弃输出来保证安全，但实用效率较低；共识解码可在不放弃的情况下实现类似效果。

## 7. 优点

- **方法新颖且实用**：利用多源数据冗余，在推理时聚合分布，无需训练阶段区分善恶源，也无需知道目标行为或中毒样本标签。
- **理论支撑**：给出KL正则化不足的数学证明，清晰阐述“硬共识”相对于“软共识”的优势。
- **覆盖多种威胁**：从显式前缀、潜意识偏好到泛化失调，展示了方法的泛用性。
- **对实际部署友好**：支持LoRA轻量微调，共识聚合可逐步计算，且可通过Quorum和语义平滑应对实际中的不完美情况。
- **实验设计严谨**：包括对比基线、消融分析、置信区间、示例分析，结论可信。

## 8. 不足与局限

- **共享行为人工设定**：所有实验中的共享行为均为“结尾添加Joke”，过于简化；未验证对更复杂任务（如代码生成、问答精度）的保留效果。
- **推理成本高**：每个生成token需通过所有参考模型前向传播，语义平滑还需额外短序列采样和嵌入计算，实际部署成本较高。论文未讨论蒸馏或缓存等优化。
- **假设（A2）在现实可能不成立**：若多个恶意源协商统一目标，或同一攻击者冒充多个源，则支持条件会被破坏。
- **缺乏对自适应攻击的鲁棒性评估**：假设源不根据解码器调整。恶意源可能主动降低共享词元概率来破坏共识，或通过负向影响回退模式等。
- **语义平滑依赖外在嵌入模型**：所用bge-base-en-v1.5可能不完美，错误匹配可能导致错误支持或错过匹配。
- **实验规模相对有限**：仅使用7B-8B模型，未见更大参数规模或更多源（>10）的验证。未在广泛基准测试（如MMLU、HumanEval）上评估性能影响。
